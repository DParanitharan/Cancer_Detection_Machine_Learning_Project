## Train/test distribution shift

Two-sample Kolmogorov-Smirnov test per fragment length, within each class. A length counts as shifted when p < 0.05 / 350 (Bonferroni). The effect size is the median absolute standardised mean difference (SMD) across lengths; below about 0.2 is conventionally small.

| Class | Train / test samples | Shifted lengths (of 350) | Median abs. SMD |
|---|---|---|---|
| early stage cancer | 781 / 368 | 165 | 0.15 |
| screening stage cancer | 490 / 230 | 139 | 0.21 |
| mid stage cancer | 453 / 206 | 50 | 0.10 |
| late stage cancer | 409 / 189 | 74 | 0.30 |
| healthy | 60 / 41 | 0 | 0.17 |

Effect sizes are small and similar for every class. Larger classes show more 'shifted' lengths because the test has more power; subsampled to the healthy class's size (60 / 41), no class shows a significant shift. So the healthy class is not shift-free, only too small to detect it.

## Open provenance questions

These cannot be answered from the files and must be checked with whoever produced the data:

- Were healthy and cancer samples collected at the same sites and sequenced in the same batches?
- Do the groups differ in age or sex? Cancer patients are usually older, and age changes cfDNA.
- Can one patient appear more than once (for example, repeat draws) across train and test?
- How was the train/test split made (random, by site, by time)?
